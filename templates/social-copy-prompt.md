# Social Media Copy Prompt Template

Use this after your reel is rendered. Generate captions for each platform.

---

## Instagram Caption Prompt

```
Write an Instagram Reel caption for a video about: [TOPIC]

The video hook is: "[HOOK]"
The key insight is: "[BEAT 4 REVEAL TEXT]"
The twist is: "[BEAT 5 TWIST TEXT]"

RULES:
1. First line = the hook (this shows before "...more")
2. Second paragraph = expand on the insight (2-3 sentences)
3. Third paragraph = identity statement ("The developers who...")
4. End with a soft CTA: "[CTA FROM CALENDAR]"
5. Add one question that invites comments
6. Tone: consultant briefing, not marketer pitching
7. NO emojis in the first line
8. Maximum 3 emojis total (subtle, professional)

HASHTAGS (use these + add 5 relevant ones):
#luxuryrealestate #realestateleads #aiautomation
#propertydevelopment #realestatetechnology

EXAMPLE OUTPUT:
---
Your sales team called 40 leads today. Three were real.

The other 37? Browsing. Window shopping. Time vampires dressed
as buyers. Your closers spent 6 hours pitching to people who
were never going to spend $2M.

The developers closing deals consistently right now aren't
working harder. They're letting AI figure out who's real before
a single call gets made.

Save this if you manage a team handling luxury leads.
What's your team's lead-to-close ratio? 👇

#luxuryrealestate #realestateleads #aiautomation
#propertydevelopment #realestatetechnology
#leadgeneration #salesautomation #proptech
#luxuryhomes #closingdeals
---
```

## YouTube Shorts Description Prompt

```
Write a YouTube Shorts description for a video about: [TOPIC]

The hook is: "[HOOK]"

RULES:
1. First line = hook (appears in search)
2. 2-3 sentences expanding the insight
3. End with: "Follow for weekly breakdowns on AI in luxury real estate."
4. Include 5 relevant keywords naturally
5. Keep under 200 characters for the visible portion
```

---

## LinkedIn Video Post Prompt (Optional, for professional reach)

```
Write a LinkedIn post for a short video about: [TOPIC]

RULES:
1. Open with a bold statement or statistic
2. Write in short paragraphs (1-2 sentences each)
3. Use line breaks liberally (LinkedIn rewards scroll depth)
4. End with a question that invites professional discussion
5. Tone: thought leader sharing industry insight
6. NO hashtags in the body — add 3-5 at the very end
7. Tag relevant industry groups if applicable
```

---

## Review Checklist for All Platforms

- [ ] First line is compelling (shows before "...more")
- [ ] No salesy language ("buy now", "limited time", "click link")
- [ ] CTA feels natural, not forced
- [ ] Hashtags are relevant (not generic #viral #trending)
- [ ] Caption matches the video tone (educational, not promotional)
- [ ] Grammar and spelling checked
- [ ] Would you engage with this post if you saw it?
