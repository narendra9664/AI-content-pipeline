# frontdesk AI — product explainer (Remotion)

A 33-second, 1920×1080 motion-graphic explainer of what frontdesk AI does:
**track** every buyer signal → **rank** leads by intent → **follow up** automatically.
Everything on screen is React code (no stock footage, no After Effects).

| Scene | What it shows |
|---|---|
| Hook | "Your hottest buyer visited your listings 6 times this week. Nobody called them." |
| Problem | Leads from every channel orbiting a hub, then collapsing into it |
| Brand | Orb + wordmark reveal, "Track → Rank → Follow up" |
| 01 Track | 3D lead-profile panel, activity timeline, intent score counting to 92 |
| 02 Rank | Lead queue re-sorting itself by intent, top 3 flagged HOT |
| 03 Follow up | AI drafts and sends a personal message, buyer replies, hot lead routed to an agent |
| Outro | "Never lose a ready buyer again." + typed CTA |

## Render

```bash
cd explainer
npm install
npx remotion studio src/index.ts          # live preview / scrub the timeline
npx remotion render src/index.ts Explainer out/explainer-silent.mp4
node scripts/mix-audio.mjs out/explainer-silent.mp4 out/explainer.mp4   # music + SFX, -16 LUFS
```

- Needs `ffmpeg` on PATH for the audio mix (or set `FFMPEG=/path/to/ffmpeg`).
- On machines that can't download Remotion's browser, point it at a local one:
  `REMOTION_BROWSER=/path/to/chrome-headless-shell npx remotion render ...`
- `node scripts/qa-stills.mjs Explainer 30 200 500` renders half-size PNGs of chosen frames for review.

## Changing it

- **Copy and data** live in the scene files under `src/scenes/` (lead names, events, scores, messages).
- **Timing** lives in `src/timeline.json`: scene lengths, transition lengths, and every sound-effect cue
  (frame offsets are relative to the start of each scene, so editing one scene doesn't break the others).
- **Brand** tokens are in `src/theme.ts` (colours from `brand/config.json`).
- Kinetic text markup: `*blue accent*`, `_gold accent_`, `~red accent~`.

## Assets and licensing

- Font: Inter (SIL Open Font License), bundled from `@fontsource/inter`.

## Pipeline

1. **Voiceover:** ElevenLabs, `eleven_multilingual_v2`. The social videos use the voice "Bryan" (sped up 10%, 8% for W1 originally). The website film W1 uses "Harper - Confident, Clear and Cool" (`c1uwEpPUcC16tq1udqxk`) at natural speed (tempo 1.0). Save it to `public/series/vo/<id>-raw.mp3`.
2. **Align:** `FFMPEG=… python3 scripts/align_vo.py <id> 1.1 "<script>"`.
   - Speeds the voice up with `atempo` and writes `public/series/vo/<id>.mp3`.
   - Force-aligns every word with pocketsphinx and writes `src/series/vo/<id>.json`.
   - Scenes key off real word times, e.g. `at(vo, 'beneath')`, so visuals land exactly on the spoken word.
3. **Render and finish:**
   ```bash
   npx remotion render src/index.ts V1 out/series/V1-raw.mp4
   FFMPEG=… python3 scripts/finalize.py out/series/V1-raw.mp4 out/series/V1.mp4   # -14 LUFS / -1.5 dBTP
   ```
4. **QA:** run `node scripts/qa-stills.mjs V1 30 150 400`, then `python3 scripts/sheet.py out/qa/V1 4 405` for contact sheets.

## Layout

- `src/series/theme.ts`: the 10 palettes (colours, display font, weight).
- `src/series/kit/`: shared building blocks.
  - `Stage`: animated background.
  - `Text`: VO-synced headlines and captions.
  - `Frames`: phone and browser frames, plus the 3D layer stacks.
  - `Site`: the demo property site "VELORIA" and its tracking layer.
  - `Lead`: score ring, ranked queue, lead card.
  - `Chat`: messages and toasts.
  - `Misc`: chips, cursor, camera, clock.
  - `Logo`: the FD mark, which draws itself, and the end card.
  - `Audio`: VO, music and SFX cues.
- `src/series/videos/*.tsx`: one file per video.
- `src/series/Stills.tsx`: product stills for the website.
- `src/series/Covers.tsx` + `scripts/render-covers.mjs`: post covers and thumbnails. The cover renders a video frame with its spoken text hidden, then adds a hook title.
- `scripts/make_srt.py`: `.srt` subtitles from the aligned voiceover (`out/series/captions/`).
- `src/series/videos/CaseStudy.tsx`: video 11, a case-study template. Copy `case-study.example.json`, fill in **measured** client numbers, then run `npx remotion render src/index.ts CaseStudy out/series/CaseStudy-raw.mp4 --props=case-study.json`.

Captions, schedule and outreach scripts for posting the series are in `output/explainer-series/POSTING-KIT.md`.

## Pipeline (no voiceover)

1. **Timing:** `python3 scripts/synth_vo.py ig01 "<script>" --wpm 175 --pause 1.25`.
   - Writes `src/series/vo/ig01.json` in the same shape as a real aligned voiceover, so `at()`, `SpokenHeadline` and `make_srt.py` work unchanged.
   - `--pause` stretches the pauses at punctuation so a line can be read before the next one replaces it.
   - A standalone `[+1.5]` token holds for 1.5 s, for example IG01's countdown before the answer.
2. **Render and finish:** as above (`npx remotion render src/index.ts IG01 out/series/IG01-raw.mp4`, then `finalize.py`). `<Soundtrack>` is used without its `vo` prop.
3. **QA:** `node scripts/qa-stills.mjs IG01=30,200,400 IG02=60,300` renders stills for several videos from one bundle.
4. **Covers and subtitles:** `node scripts/render-covers.mjs IG01 …` and `python3 scripts/make_srt.py`.

Shared pieces for this series (stamp, comment prompt, progress ring, rewind sweep, log rows) are in `src/series/kit/Social.tsx`. Captions and the posting schedule are in `output/instagram-series/POSTING-KIT.txt`.
